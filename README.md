# PrimeTech Decorators
Static English-language business website. Run `node serve.cjs` and visit http://127.0.0.1:4173.
Images originate from the company Instagram profile supplied by the user. Contact details transcribed from its project artwork. Google Fonts serves DM Sans. Email buttons launch the visitor's email application; no form data is collected.
The local Impeccable launcher failed with cache_directory_failed; design tools could not run. Browser preview initially timed out. No automated visual approval is claimed.
